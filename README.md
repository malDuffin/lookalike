# Lookalike

A 3D character studio. Recolor hair, skin, and eyes on a cartoon boy — pick colors by hand, or match them from a photo or webcam.

## Features

- Live hair / skin / eye recolor on the model
- Face match from a photo or camera
- Animation clips
- QR share button (bottom right) — scan to open the current page on your phone

## Stack

React 19, TanStack Start, React Three Fiber, MediaPipe Face Landmarker.

## Scripts

- `npm install`
- `npm run dev` — local studio
- `npm run build` — production build
